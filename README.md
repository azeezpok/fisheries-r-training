# fisheries-r-training
This repository contains R scripts, sample datasets, and practical exercises developed for training on Fundamentals of R Programming and Practical Workflows for Fisheries Data.

The training introduces participants to R programming and demonstrates how R can be used for fisheries data management, exploratory data analysis, visualisation, and basic fisheries research applications.

Learning Objectives

Understand the fundamentals of R programming.

Import, inspect, and manage fisheries datasets.

Perform data cleaning and quality checks.

Calculate catch per unit effort (CPUE).

Summarise fisheries data by island and other relevant categories.

Construct length-frequency distributions.

Analyse length-weight relationships.

Explore relationships between fisheries and environmental variables.

Handle missing values and export analytical results.

Create publication-quality graphs using ggplot2.

Sample Datasets

Catch and effort data: Demonstrates basic fisheries data analysis and CPUE calculations.

Length-weight data: Demonstrates length-frequency analysis and length-weight relationships.

Environmental data: Demonstrates the integration of environmental variables with fisheries observations.

The datasets are illustrative examples intended for training and practice, not official fisheries statistics.

Software Requirements

R

RStudio Desktop (recommended)

Required R packages: tidyverse, including dplyr, readr, and ggplot2
